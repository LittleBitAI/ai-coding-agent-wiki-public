# 화면 확인

`craft/screen-follows-the-purpose`와 `craft/screen-ownership-before-wiring`을 따른다.
사용자 목적을 한 문장으로 정하고 화면 구성을 확인한다.
실제 화면에서 버튼과 상태 전환을 확인하고 글자, 색, 여백 순서로 살핀다.
되돌리기 어려운 동작은 허가 없이 누르지 않는다. 화면 확인과 코드 검사를 구분해 보고한다.
