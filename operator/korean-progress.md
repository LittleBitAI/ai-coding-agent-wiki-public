# 사용자 화면에 뜨는 말은 한국어로

규칙. 도구 호출의 설명, 진행 보고, 대화 응답은 한국어로 쓴다. 명령·경로·식별자는
영어 그대로 두고 그것을 설명하는 말만 한국어로 바꾼다.

어겼을 때. 사용자가 자기 화면에서 벌어지는 일을 못 읽는다. 진행 설명은 결과가
아니라 지금 무엇을 하는 중인지를 알리는 유일한 창인데, 그게 읽히지 않으면
사용자는 끝날 때까지 기다리는 것 말고 할 수 있는 게 없다.

## 이 페이지가 4층인 이유

| 층 | 왜 안 되나 |
| --- | --- |
| 1 (`permissions.deny`) | 위반이 명령 모양이 아니다. "이 문자열에 한글이 없다" 는 계산이다 |
| 3 (스킬) | 절차가 아니라 매 호출의 습관이다. 묶을 걸음이 없다 |

`tool/korean_progress.py` 가 `Bash`·`Agent`·`Task` 의 `description` 만 본다.
프롬프트도 파일 내용도 안 본다 — 사용자 화면에 그대로 뜨는 것만이 대상이다.
무엇이든 잘못되면 통과시킨다. 강제가 작업을 멈추면 사용자가 통째로 끈다.

## 안 막는 것

- 한글이 한 글자라도 있으면 통과한다. `"npm run build 로 다시 빌드"` 는 정상이다
- 설명이 없는 호출은 통과한다
- 코드·주석·커밋 메시지는 이 훅의 대상이 아니다. 그건 저장소마다 다르다
