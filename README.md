# AI Coding Agent Wiki

프로젝트 규칙과 문서를 Claude Code·Codex CLI에서 함께 사용하는 로컬 도구입니다.
웹 채팅에서 프로젝트에 대해 질문하고, 근거를 찾은 답변과 쉬운 설명을 전환해서 볼 수 있습니다.
각 팀원은 자기 PC와 자기 CLI 계정으로 실행합니다.

이 공개본에는 실제 프로젝트의 대화·사례·개인 설정이 없습니다. 규칙은 일반적인 사용 지침으로 정리했고,
검사에는 가상 프로젝트를 사용합니다. 기존 개인용 저장소와 Git 이력을 공유하지 않습니다.

## 시작하기

Git, Python 3.11 이상, Node.js 22.12 이상과 사용할 CLI를 준비합니다.
설치·로그인 방법은 [팀원 설치 안내](docs/chat-setup.md)에 있습니다.

```powershell
# Codex CLI를 사용하는 경우
python tool/setup_chat.py install --agent codex

# Claude Code를 사용하는 경우에는 --agent claude
# 두 가지를 함께 쓰면 --agent both
.\tool\chat.cmd
```

브라우저에서 `http://127.0.0.1:8787`을 엽니다.
macOS·Linux에서는 `.venv/bin/python tool/chat.py`로 실행합니다.
서버는 개인 PC에서만 사용하며 종료는 실행한 터미널의 `Ctrl+C`입니다.

## 프로젝트 규칙 연결

[hooks 설치 안내](docs/hooks-setup.md)에 따라 **대상 프로젝트의** `.wiki/adapter.toml`을 작성합니다.
설정 파일에는 검사 명령 등 그 프로젝트의 값을 넣습니다. 이 위키에 복사할 필요가 없습니다.
`tool/setup_agents.py`는 기존 `tool/apply.py`로 설정을 병합하고 검사합니다.
기존에 있던 다른 hooks와 설정은 보존합니다.

`operator/`와 `craft/`는 공용 규칙, `skills/`는 선택해서 설치하는 작업 절차입니다.
규칙 묶음에는 한국어 진행 보고와 일부 도구 차단이 있으므로 설치 전에 읽어 보세요.
스킬 파일은 각 CLI의 스킬 설치 방식으로 별도로 연결해야 하며 hooks 설치가 이를 대신하지 않습니다.

## 확인과 한계

- [설명 품질 기준](docs/quality.md): 쉬운 설명은 아직 품질 합격으로 판정하지 않았습니다.
- [개발·검사](docs/development.md): 설치 검사, 호스트 이벤트, 답변 품질을 구분합니다.
- [공개 사본 검증 결과](docs/verification.md): 실행한 검사와 남은 확인을 기록했습니다.
- [공개본 갱신](docs/publishing.md): 개인 기록을 보존하면서 공개 가능한 변경만 반영합니다.
- 원문 검색과 쉬운 설명은 서로 다른 영어 프롬프트를 사용하고, 출력은 한국어입니다.
- 원문 검색은 선택한 프로젝트를 읽습니다. CLI를 통해 선택한 모델 제공자에게 필요한 문맥이 전달됩니다.
  로컬 서버라는 표현은 모델 추론까지 오프라인이라는 뜻이 아닙니다.
- 웹 계정 관리나 여러 사용자를 위한 공유 서버 기능은 없습니다.
- 이 저장소를 GitHub에 올리는 것만으로 서버가 자동 실행되지는 않습니다.

대화, 분석 기록, 프로젝트 설정, CLI 설정, 생성한 지도는 기본적으로 Git에서 제외됩니다.
이를 강제로 추가하거나 다른 이름의 문서에 복사하면 공유될 수 있으므로 공개 전에는 변경 내용을 확인하세요.
